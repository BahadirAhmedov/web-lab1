# Зерно — магазин кофе

Учебный проект: одностраничный магазин кофе. Можно посмотреть каталог, добавить зёрна в корзину, поменять количество, удалить лишнее и оформить заказ через форму

Всё работает в браузере, без сервера. Корзина хранится в `localStorage`, поэтому после перезагрузки страницы остаётся на месте

## Стек

HTML5, CSS3 (Flexbox, Grid, медиа-запросы) и просто JavaScript

## Что умеет

- Каталог из шести позиций с ценой и описанием вкуса
- Добавление в корзину, кнопки «+» и «−», удаление товара
- Пересчёт итоговой суммы
- Сохранение корзины в `localStorage`
- Форма заказа в модальном окне и сообщение об успехе
- Адаптив под телефон, планшет и десктоп

## Структура

```
index.html      разметка страницы
css/style.css   стили, в конце файла — медиа-запросы
js/script.js    логика корзины
assets/img/     картинки товаров
```

## Запуск

Открыть `index.html` в браузере. Или поднять локальный сервер:

```
python3 -m http.server 8000
```

И зайти на http://localhost:8000
